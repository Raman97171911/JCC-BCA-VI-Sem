## Course Name: Ethical Hacking and Penetration Testing
**Course Code: BCACT-603**
**Course Credit: 3-0-1**
**COURSE OBJECTIVES:**
●      To learn the ethical hacking methodology and its different stages which includes footprinting, scanning, and enumeration.
●      To understand the concepts of Vulnerability Assessment and its importance in identifying and managing vulnerabilities in systems.
●      To familiarize different System Hacking Techniques.
●      Gain an understanding of Mobile, Cloud, and IoT Concepts and the differences between IoT and OT Hacking.

**COURSE CONTENT**:
**UNIT 1:**  **Introduction**                                                                                 
Introduction to Ethical hacking, Types of hackers, The Hacking Methodology, Ethical Hacking Concepts, Footprinting, and Reconnaissance - Footprinting Concepts, Footprinting through Search Engines, Footprinting through Web Services, Footprinting through Social Networking Sites, Website Footprinting, Email Footprinting, Whois Footprinting, DNS Footprinting, Network Footprinting, Footprinting through Social Engineering, Footprinting Tools, Footprinting Countermeasures.

**UNIT 2: Scanning and Enumeration**                                                                                
Network Scanning Concepts, Scanning Tools, Host Discovery, Port and Service Discovery, OS Discovery (Banner Grabbing/OS Fingerprinting), Scanning Beyond IDS and Firewall, and Network Scanning Countermeasures. Enumeration, Enumeration Concepts: NetBIOS Enumeration, SNMP Enumeration, LDAP Enumeration, NTP and NFS Enumeration, SMTP and DNS Enumeration, Other Enumeration Techniques, Enumeration Countermeasures.

**UNIT 3: Vulnerability Analysis and System Hacking**                             
Vulnerability Assessment Concepts, Vulnerability Classification, and Assessment Types, Vulnerability Assessment Tools, Vulnerability Assessment Reports. System Hacking, Gaining Access, Escalating Privileges, Maintaining Access, Clearing Logs. Evading IDS, Firewalls, and Honeypots - Evading NAC and Endpoint Security.

**UNIT 4: System Hacking Techniques**                                                                    
Sniffing Technique: MAC Attacks, DHCP Attacks, ARP Poisoning, Spoofing Attacks, DNS PoisoningSocial Engineering Techniques: Insider Threats, Impersonation on Social Networking Sites, Identity TheftDenial-of-Service: Botnets, DoS/DDoS Attack Techniques, DDoS Case StudySession Hijacking Techniques: Application-Level Session Hijacking, Network-Level Session Hijacking, Session Hijacking Tools, Session Hijacking CountermeasuresWeb Servers and Web Applications Hacking Techniques: Web Server Attack Methodologies, Web Application Hacking Methodology, Web API, Webhooks, and Web Shell Hacking Wireless Networks: Wireless Concepts, Wireless Encryption, Wireless Threats, Wireless Hacking Methodology, Wireless Hacking Tools, Bluetooth Hacking  

**UNIT 5: Hacking Mobile Platforms, Cloud and IoT**                                                 
Mobile Platform Attack Vectors, Hacking Android OS, Hacking iOS, IoT Concepts, IoT and OT Hacking, IoT Hacking: IoT Attacks, IoT Hacking Methodology. OT Hacking: OT Concepts, OT Attacks, OT Hacking Methodology, Cloud Computing Concepts, Container Technology, Manipulating Cloud Trial Service, Cloud Security.

                          ************Course Name: Security Operations and Incidence Response************ 

**Course Code: BCACT-604**
**Course Credit:** **3-0-1**

**COURSE OBJECTIVES:**
●      To learn the skills necessary to identify and mitigate security threats using a variety of techniques and tools.
●      To understand how computer forensics is used as a powerful technique in digital investigation.
●      To make it PSOsible for students to learn how security incidents are handled and prevented.
●      To gain knowledge of the common vulnerabilities in web applications.
●      To know the importance of regulations and standards in the field of cybersecurity.

**COURSE CONTENT**:
**UNIT 1: Security Operations**                                                                                 
Network reconnaissance and discovery, Shell environments, Network traffic capture, Exploitation frameworks, File manipulation, Password crackers, Data sanitization, Network and Vulnerability scanning, Log analysis, SIEM.

**UNIT 2: Digital Forensics**
Overview of digital forensics, preparing for digital investigations: Following legal processes, understanding private-sector Investigations, Digital forensics methodology, Evidence collection/acquisition, Investigation and analysis of evidence, Understanding storage formats for digital evidence, Overview of Windows forensics, Network forensics, Cloud forensics, and Mobile forensics. 

**UNIT 3: Incidence Response**
Incident response lifecycle, Incident response plans, Incident response process, Incident handling infrastructure and facilities requirements, detection and analysis, process, tools and techniques, attack vectors, recognizing signs of an incident, precursors, indicators and historical organization data, incident correlation, review of logs and vital system parameters, incident handling checklist, documentation, and reporting.

**UNIT 4: Application Security**
Input validations, Secure cookies, HTTP headers, Code signing, White listing and Blacklisting, Secure coding practices, Static code analysis, Dynamic code analysis, Fuzzing, hardening – Operating systems, open ports and services, registry. Disk encryption, Patch management, Trusted platforms, sandboxing.

**UNIT 5: Regulations and Standards**
Center for Internet Security (CIS), National Institute of Standards and Technology (NIST) - RMF/CSF, International Organization for Standardization (ISO) -27000 series, IT Act India, Payment Card Industry Data Security Standard (PCI DSS), Health industry - HIPAA, SOX.
